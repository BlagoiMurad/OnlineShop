
# OnlineShop API

A RESTful Web API for an online shop built with ASP.NET Core 8.0.

## Technologies
- ASP.NET Core 8.0
- Entity Framework Core
- Microsoft SQL Server
- ASP.NET Identity
- NUnit & Moq

## Features
- Product management (CRUD)
- Category management
- Order processing
- User authentication and authorization
- Admin panel
